## 목적과 배경

사용자는 서로 다르게 만들어진 여러 발표자료의 배경 화면을 하나로 통일하려고 합니다. 통일된 배경은 엡사이(Absci) 회사의 투자자 안내 웹사이트(https://investors.absci.com) 이미지를 가져와 사용합니다. 동시에 기존에 개별적으로 설정된 요소들의 움직임이나 화면 넘김 효과는 지우지 않고 보존합니다. 이를 통해 발표자료의 시각적 일관성을 확보하면서도 화려한 발표 연출은 유지하는 것이 기본 목적입니다. 더불어, 새 배경을 적용하는 과정에서 각 파일에 중복되어 있는 공통 보정 기능(인쇄 시 잘림 방지 등)을 하나로 모아 앞으로의 유지보수 작업을 더욱 쉽게 만듭니다.

## 결정사항

| # | 결정 | 근거 |
|---|---|---|
| 1 | 엡사이 투자자 웹사이트(https://investors.absci.com)의 이미지를 배경으로 사용합니다. | 사용자가 요구사항 인터뷰 단계에서 기준 인터넷 주소를 명시했습니다. |
| 2 | 애니메이션과 화면 전환 효과를 기존대로 둡니다. | 사용자가 기존에 설정된 다채로운 시각 효과들을 보존하기를 원했습니다. |
| 3 | 공통 최적화 코드를 하나의 테마 파일로 모읍니다. | 발표자 화면 맞춤 기능이나 인쇄용 보정 기능이 누락되는 실수를 막습니다. |
| 4 | 차트와 다이어그램 색상을 자동으로 연동시킵니다. | 고정된 옛날 색상 때문에 새 배경에서 글자가 보이지 않는 문제를 막습니다. |
| 5 | 기준 화면 크기를 기존과 동일하게 고정합니다. | 글자 간격이나 표 정렬이 틀어지는 심각한 문제를 미연에 방지합니다. |

## 검토한 대안과 트레이드오프

| 결정 | 채택안 | 기각안 | 기각 이유 |
|---|---|---|---|
| 명암비 해결 방식 | 어두운 바탕 위에 배경 이미지의 불투명도(opacity)를 낮춰 겹쳐서 어둡게 만듦 | 글자 색상을 더 밝은 색으로 일괄 변경함 | 글자 색상을 강제로 바꾸면 발표자가 설정한 강조 색상까지 지워질 위험이 있습니다. |
| 공통 기능 분리 | 중복된 화면 최적화 코드를 찾아 하나의 파일로 합침 | 화면 최적화 코드를 각 문서 파일에 그대로 남겨둠 | 문서 개수가 늘어날 때마다 최적화 코드를 빼먹고 작성하는 실수가 늘어납니다. |
| 이전 테마 검사 | 시각 검사(CI) 설정에서 이전 테마 파일을 검사 대상에서 지움 | 이전 테마 파일 검사 코드를 그대로 둔 채 새 파일 검사를 추가함 | 이미 삭제된 과거 파일을 찾지 못해 오류가 발생하며 배포가 멈춥니다. |

## 동작 방식

새로운 엡사이 테마 배경은 공통 디자인 파일에 담깁니다. 모든 발표자료 문서는 이 공통 파일을 참조하여 화면을 그립니다. 발표자료 문서 안에는 공통 테마 설정을 제외한 실제 내용물(글자, 이미지, 차트 등)과 개별 애니메이션 설정만 남습니다. 글자가 명확하게 보이도록 어두운 기본 바탕색 위에 배경 이미지 자체의 불투명도(opacity)를 낮춰 고정적으로 어둡게 처리합니다. 차트나 다이어그램을 그리는 외부 도구들도 억지로 고정된 색 대신 공통 디자인 파일의 색상을 가져다 씁니다. 이를 통해 어떤 화면에서든 글자가 뚜렷하게 보입니다.

## 의도적 범위 제외

- 개별 발표자료 문서의 제목이나 내용을 수정하는 작업은 하지 않습니다. 이는 배경 디자인을 통일하는 이번 작업의 목적을 벗어나기 때문입니다.
- 기본으로 제공되는 애니메이션 효과 외에 새로운 화면 효과를 추가하지 않습니다. 기존 기능을 유지하는 것이 우선순위입니다.
