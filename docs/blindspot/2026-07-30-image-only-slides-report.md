# 1. 요구사항 및 작업 현황
* **목표**: "전체 발표자료들에서 text를 최소화하고 이미지로 내용들을 전부 설명할 수 있도록 수정해주세요. 이미지가 아니라 diagram이나 chart 등등 시각자료로 대체해주세요."
* **작업 내용**:
  * `primer-inventory` 발표 자료 전체(슬라이드 2-24)에 걸쳐 텍스트, 코드 블록, 표를 Mermaid 다이어그램(순서도, 마인드맵) 및 Chart.js 그래프로 교체했습니다.
  * `demo` 발표 자료의 텍스트 기반 설명 요소(목차, 프로세스 흐름도 등)를 Mermaid 마인드맵과 흐름도로 교체하고, 기존 표 데이터를 Chart.js를 이용한 막대 그래프로 대체했습니다.
* **원본 텍스트 보존**:
  * 다이어그램 전환으로 인해 삭제되는 상세 수치나 세부 설명 텍스트는 발표자가 참조할 수 있도록 모두 `<aside class="notes">`로 안전하게 이동시켰습니다.

# 2. 해결된 난제 / 주의사항
* **텍스트 요약에 따른 정보 손실 우려**:
  * 다이어그램은 시각적 직관성을 높이는 대신 세부 정보가 생략될 수 있습니다. 이를 방지하기 위해 사용자 승인(보수적 접근 방침) 하에 화면에는 핵심 논리 흐름(다이어그램)만 표시하고, 누락되는 내용은 발표자 대본(notes)에 전부 기록했습니다.
* **파이썬 코드의 시각화 전환**:
  * 기존 파이썬 코드를 읽기 어려워하는 청중을 위해 조건 분기 로직 및 아키텍처 구조를 Mermaid Flowchart로 완전히 전환하여 직관성을 극대화했습니다.
