# 발표자료 시각화(Visual Redesign) 구현 노트 (Implementation Notes)

## 구현 목표
사용자 승인에 따라 기존 텍스트 중심의 발표자료(`primer-inventory`, `demo`)를 Mermaid 다이어그램(순서도, 간트 차트, 아키텍처 등) 및 Chart.js 형태의 시각 자료로 전면 교체합니다.

## 핵심 설계 결정 사항

1. **텍스트 최소화 및 스피커 노트화 방침**
   - 기존의 불릿 리스트, 설명글, 터미널 출력문, 표는 모두 `<aside class="notes">` 안으로 이동시킵니다.
   - 슬라이드의 본문은 제목(`<h2>`)과 다이어그램(`<div class="figure">`)만 남깁니다.

2. **파이썬 코드 원문 제거 결정**
   - 사용자가 세부적인 질문(파이썬 원문 코드 유지 여부)에 대해 "승인합니다"로 포괄적 승인을 하였으므로, 보수적인 접근(텍스트 최소화 극대화)을 택합니다.
   - 11번(알고리즘 구현), 13번(조건문 필터 로직) 슬라이드의 수십 줄짜리 파이썬 코드도 전부 순서도(Flowchart) 형태로 대체하여 직관적으로 동작 로직만 전달합니다.

3. **애니메이션(Fragment) 상실에 대한 대안 설계**
   - 리스트 항목별로 단계별 등장을 하던 슬라이드들은, 전체 프로세스를 담은 하나의 큰 다이어그램으로 그리되 시선의 흐름에 맞게 정렬(LR 혹은 TB)하여 시각적 혼란을 최소화합니다.
   - 다이어그램의 `style`이나 `classDef` 기능을 활용해 핵심 경로(Critical Path)를 강조합니다.

## 남은 우려 사항 (Blindspots)
- 기존 터미널의 출력 텍스트 중에는 프라이머의 세세한 위치 데이터나 Tm 값과 같은 구체적인 숫자들이 많았습니다. 이를 간트 차트(Gantt)나 순서도로 축약하면 이 미세 수치들을 화면에서 직접 읽기 힘들어집니다. 하지만 사용자가 "디테일이 손실되더라도 직관적인 이미지 1장으로 요약하는 방침"을 승인했으므로 그대로 추진합니다.
