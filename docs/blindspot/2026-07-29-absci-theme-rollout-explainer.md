## 목적과 배경

사용자는 기존 발표 자료들의 디자인을 absci.com/technology/ 웹사이트와 똑같이 맞추기를 원합니다. 웹사이트의 디자인 느낌을 모든 발표 슬라이드에 똑같이 보여주어 시각적인 통일감을 주는 것이 주된 목표입니다. 이를 위해 기존 발표 프레임워크의 뼈대는 남겨둔 채 겉모습(테마와 배경 애니메이션)만 교체하는 작업을 진행합니다.

## 결정사항

| # | 결정 | 근거 |
|---|---|---|
| 1 | 배경을 CSS 그라데이션 애니메이션으로 구현 | 웹사이트 원본 비디오 파일(MP4 등)에 의존하지 않고 비슷한 느낌을 훨씬 빠르고 가볍게 구현할 수 있습니다. |
| 2 | 밝은 모드 시 전용 밝은 애니메이션 사용 | 기존처럼 밝은 모드에서 배경을 완전히 꺼버리지 않고, 밝은 테마에 맞는 시각 효과를 새로 제공하기 위함입니다. |
| 3 | 인쇄 및 움직임 줄이기 설정 시 애니메이션 중단 | 애니메이션이 인쇄(PDF) 결과물을 망가뜨리거나 어지럼증을 유발하는 것을 막기 위해 기존 방어 장치를 유지합니다. |
| 4 | 가독성을 위한 반투명 막(scrim) 구조 유지 및 테마별 가변 적용 | 배경 이미지 위에 글씨가 안 보이는 현상을 막기 위해 막 계층 구조를 물려받되, 기본(어두운) 모드에서는 어둠 막과 흰 글씨를, 밝은 모드에서는 밝은 막과 어두운 글씨를 유동적으로 적용합니다. |

## 검토한 대안과 트레이드오프

| 결정 | 채택안 | 기각안 | 기각 이유 |
|---|---|---|---|
| 배경 구현 방식 | CSS 그라데이션 애니메이션으로 가볍게 구현 | 무거운 원본 비디오 파일을 통째로 배경에 깔기 | 성능이 저하되며 파일 용량 한도(100MB 제한)에 걸릴 수 있습니다. |
| 밝은 모드 예외 처리 | 밝은 모드 전용의 새로운 밝은 테마 애니메이션 적용 | 밝은 모드 진입 시 모든 애니메이션을 완전히 비활성화 | 화려한 시각적 효과를 포기하고 너무 밋밋한 화면만 남게 됩니다. |
| 기존 JS 방어 로직 | 불필요한 JS 로직만 걷어내고 애니메이션 중단 CSS 방어 패턴만 남김 | 기존의 복잡한 JS 및 CSS 중단 로직을 통째로 이식하기 | 새 배경은 CSS만 사용하므로 JS로 애니메이션 루프를 끌 필요가 없습니다. |

## 동작 방식

발표 화면이 열리면 화면 맨 뒤쪽 바닥에 CSS로 만들어진 부드러운 그라데이션 애니메이션이 재생됩니다. 그 바로 위에는 기본적으로 글자를 또렷하게 보이게 해주는 반투명한 어둠 막이 깔리며, 밝은 모드 시에는 이 막이 반투명한 밝은 막으로 변하고 글자 색상도 어둡게 반전됩니다. 마지막으로 맨 위에 실제 발표 내용인 글자와 그림들이 차례대로 나타납니다. 만약 화면을 인쇄(PDF)하거나 컴퓨터의 '움직임 줄이기' 옵션이 켜져 있으면, 바닥의 애니메이션은 멈추고 정지된 화면으로 바뀝니다.

## 의도적 범위 제외

- absci.com/technology/ 웹사이트의 복잡한 3D 분자 구조 그래픽이나 마우스 움직임에 반응하는 인터랙션 요소는 만들지 않습니다. 발표 자료 도구의 한계상 무거운 3D 엔진을 넣으면 발표를 넘기는 속도가 느려지고 동작이 불안정해질 수 있기 때문입니다.
