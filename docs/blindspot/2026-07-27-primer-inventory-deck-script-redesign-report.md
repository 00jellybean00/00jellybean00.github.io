## Agent 섹션 (AI 인수인계용)

### 의도 (Intent)

`slides/primer-inventory/index.html` 한 파일에 세 가지를 넣는다.

1. **발표자 스크립트**: 28장 전부에 `<aside class="notes">`. reveal.js notes 플러그인의 speaker view(S 키)에서 스크롤 없이 읽히도록 길이를 제한한다.
2. **캔버스 재설정**: `Reveal.initialize({ width: 1280, height: 800 })`. `--r-main-font-size` 는 슬라이드 크기와 무관한 고정값이므로 42px → 48px 로 보정한다 (700/800 = 0.875, 42/0.875 = 48).
3. **테마/애니메이션**: euiyun.com 세미나 덱 계열의 다크 팔레트와 rise-in 등장. 기존 fragment 기반 수동 진행을 자동 시차 등장으로 대체한다.

공용 자산은 건드리지 않는다. 덱 내부 오버라이드로만 해결한다.

### 제약 (Constraints)

- 수정 금지: `assets/galaxy.css`, `assets/galaxy-reveal.css`, `assets/starfield.js`, `assets/starfield.selftest.js`, `slides/demo/index.html`, 대상 저장소 `primer-inventory`.
- 터미널 출력과 코드 발췌는 원본과 바이트 단위로 같아야 한다. 불가피한 변형(줄 접기, 설명글 생략)은 덱 안에 표시한다.
- 발표자 화면 노트는 스크롤 없이 보여야 한다 (사용자 지시).
- 밝은 모드에서 대비 AA 4.5:1 이상.
- `--r-*` 변수 15개는 `galaxy-reveal.css` 가 `.reveal` 에 재선언하므로 `:root` 가 아니라 `.reveal` 에 설정해야 한다.
- `:root.light` 는 특정성 (0,2,0)으로 덱의 `:root` (0,1,0)를 소스 순서와 무관하게 이긴다. 팔레트는 반드시 쌍으로 작성한다.

### 의도적 범위 제외

- **`max-height: none` 의 대체 안전장치를 만들지 않았다.** 슬라이드 세로 800px가 유일한 상한이고, 넘치면 조용히 잘린다. 현재 여유 최소 10px. 콘텐츠가 늘면 수동 재측정이 필요하다.
- **`slides/demo/index.html` 에 같은 테마를 적용하지 않았다.** 사용자 지시가 이 덱 한정이다.
- **공용 `assets/` 에 테마를 승격하지 않았다.** 다른 페이지 회귀 위험을 피했다. 재사용이 필요해지면 그때 승격한다.
- **`<pre>` 슬라이드의 section `scrollWidth` 2px 초과를 고치지 않았다.** 테두리 2px 때문이며 시각적 영향이 없다.
- **설계 문서의 확인 항목 8개를 갱신하지 않았다.** 이번 결함 4건을 그 8개가 못 잡았다는 사실만 구현 노트에 기록했다.

### 구현 노트 요약

계획 이탈 (설계 문서와 달라진 것):

1. 본문 글자색을 참고 덱의 순백 대신 `#E2E6F0` 로 낮췄다. 참고 덱은 순백에 검정 그림자를 함께 쓰는데, 그 그림자가 등폭 코드 정렬을 흐린다.
2. 설계값 8개 중 7개를 실측으로 다시 계산했다. 등폭 advance 폭 어림값(0.600)이 실제(0.602)와 달라 102칸 줄에서 4px 넘쳤다.
3. 스크립트 길이 상한을 140자에서 8줄로 바꿨다. 140자는 연속 글 기준이었고, 실제 노트는 줄 단위라 제약이 다르다. 첫 초안은 140자를 지키고도 21장이 넘쳤다.
4. 등장 순서를 `nth-child` 대신 `--i` 커스텀 프로퍼티로 바꿨다. `nth-child` 는 비대상 형제를 세고, 감싸는 상자에서 1부터 다시 세고, 미리 정한 단계 수를 넘으면 조용히 무너진다.

보수적 선택:

- 발표자 화면 노트에 38px 여유가 남았지만 8줄 상한을 늘리지 않았다. 한 줄이 30px이라 글꼴이 다르면 바로 넘친다.
