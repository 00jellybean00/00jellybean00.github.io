# 발표자료 전면 이미지화 전환 인터뷰 (Requirements Interview)

사용자께서 요청하신 "전체 발표자료들에서 text를 최소화하고 이미지로 내용들을 전부 설명할 수 있도록 수정"하는 작업은 기존 슬라이드의 구조와 내용을 완전히 재구성하는 파괴적인(destructive) 변경을 수반합니다.

성공적인 구현을 위해 작업을 시작하기 전 아래의 핵심 사항들에 대한 명확한 결정이 필요합니다.

## 결정 필요 사항 (Questions)

**Q1. 삽입할 이미지의 출처와 에셋 확보 방안**
현재 `slides/` 하위의 덱(`demo`, `primer-inventory`)에는 기존 텍스트를 대체할 만한 시각 자료(이미지)가 존재하지 않으며 모두 HTML 텍스트 및 코드/수식으로 이루어져 있습니다.
텍스트를 대체할 이미지들은 어디서 가져오나요?
- A: "제가 지정된 폴더에 직접 제공하겠습니다."
- B: "AI 이미지 생성기(DALL-E, Midjourney 등)를 이용해 텍스트에 맞는 개념도를 직접 생성해서 넣어주세요."
- C: "기존 Mermaid 다이어그램이나 코드를 캡처한 형태의 이미지로 변환해 주세요."

**Q2. 텍스트 최소화의 수준 (접근성 고려 여부)**
모든 내용을 이미지로 대체할 경우 스크린 리더 접근성과 검색 가능성(SEO)이 떨어집니다.
- A: "슬라이드 캔버스 자체에는 텍스트를 최소화하되, 접근성을 위해 `aria-label`이나 보이지 않는 스크립트 노트를 통해 텍스트 원본을 보존해 주세요."
- B: "접근성은 고려하지 않아도 좋으니, 완전히 화면에서 텍스트 태그를 제거하고 이미지 뷰어처럼 만들어 주세요."

**Q3. 정보 손실 및 동적 애니메이션(Fragment) 포기 여부**
코드나 수식 등 복잡한 내용을 이미지 1장으로 요약하면 필수 디테일이 생략될 수 있습니다. 특히 기존 슬라이드는 항목이 순차적으로 나타나는 `<li class="fragment">` 애니메이션과 코드 줄 단위 강조(`data-line-numbers`) 효과를 적극 활용하고 있습니다. 이를 단일 이미지로 대체하면 이 모든 동적 효과가 파괴됩니다.
- A: "모든 애니메이션 효과와 디테일 손실을 감수하고 슬라이드 1장당 통이미지 1장으로 요약해 주세요."
- B: "애니메이션 효과를 유지하기 위해, 각 단계별(프래그먼트별) 파생 이미지를 여러 장 렌더링해서 겹쳐 띄워주세요."
- C: "애니메이션이 들어간 부분과 필수 코드 블록 등은 예외적으로 텍스트/스크립트로 남겨두세요."

**Q4. 스피커 노트 보존 및 플러그인 제거**
화면 렌더링을 100% 이미지로 교체할 경우 기존 렌더러 플러그인(Mermaid, Chart.js, KaTeX)은 모두 제거하게 됩니다. 단, 화면에 보이지 않는 발표자 대본(`<aside class="notes">`)은 어떻게 할까요?
- A: "발표자 대본은 DOM 내부에 텍스트로 보존해서 단축키 `S`를 눌렀을 때 계속 동작하도록 파싱 및 재주입해 주세요."
- B: "스피커 노트도 필요 없으니 완전히 날려버리세요."
