# 슬라이드 테마 통일 요구사항

- 날짜: 2026-07-30
- 상태: 확정
- 관련 문서: 없음

## 요청 배경

사용자는 모든 발표자료의 시각적 스타일(테마)을 하나로 통합하기를 원합니다. 기존 발표자료들은 서로 다른 배경과 애니메이션을 사용하고 있습니다. 일관된 시각적 경험을 제공하는 것이 전체 작업의 목적입니다.

## Unknowns 4분면

| 분면 | 항목 |
|---|---|
| Known Knowns (명시된 요구사항) | 모든 발표자료를 맞춤형 테마(absci 테마)로 통일해야 합니다. 배경은 엡사이(Absci) 웹사이트 주소를 참고하여 반영해야 합니다. 화면 전환 효과(트랜지션)와 텍스트 등 요소의 순차적 등장 효과(애니메이션)는 현재 설정된 다양한 효과를 모두 그대로 유지해야 합니다. |
| Known Unknowns (답이 필요한 질문) | 배경 디자인에 참고해야 할 엡사이(Absci) 웹사이트의 정확한 인터넷 주소는 무엇인가요? 발표자료별로 다르게 설정된 예외적인 디자인 코드를 어디까지 공통 파일로 옮겨야 할까요? |
| Unknown Knowns (인터뷰로 드러난 암묵적 선호) | 사용자는 모든 애니메이션을 하나로 통일하는 것보다는 기존 발표자료에 개별적으로 설정된 다채로운 화면 전환 효과와 요소 애니메이션을 그대로 보존하는 것을 선호합니다. |
| Unknown Unknowns (미지 영역 — blindspot-pass 대상) | 일부 슬라이드에서 변경된 테마를 적용했을 때 글자가 보이지 않는 시각적 충돌(회귀 버그)이 발생할 가능성이 있습니다. 외부 기능(서드파티 라이브러리)과 맞춤형 테마가 서로 충돌할 수 있는 설정이 있을 수 있습니다. |

## 확정 요구사항

1. 모든 발표자료는 맞춤형 테마(absci 테마)로 디자인이 변경됩니다. (근거: 인터뷰 응답 "absci 테마로 통일해주세요. 배경을 absci url을 참고해서 반영해주세요")
2. 슬라이드가 넘어갈 때의 화면 전환 효과(트랜지션)와 요소가 순차적으로 등장하는 효과(애니메이션)는 기존 설정을 변경하지 않고 모두 그대로 유지합니다. (근거: 인터뷰 응답 "현재 설정되어 있는 다양한 기본 애니메이션 효과들을 그대로 유지합니다.")
