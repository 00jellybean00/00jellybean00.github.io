## 용어 안내

- **대비비**: 글자와 배경의 밝기 차이를 나타내는 값입니다. 클수록 잘 읽힙니다.
- **코드 상자**: 프로그램 글을 담는 어두운 상자입니다. 밝은 모드에서도 어두운 채로 남습니다.
- **인라인 코드 칩**: 문장 안에 섞여 나오는 짧은 프로그램 글입니다. 코드 상자 **밖**에 있습니다.
- **화면 렌더링 검사**: 브라우저로 실제 그려 본 뒤 확인하는 자동 검사입니다.
- **화면 파일 안에 직접 적은 규칙**: 공용 파일이 아니라 그 화면 파일 안에 쓴 꾸밈 규칙입니다.

## 스캔 원본 요약

### conventions

- 공용 CSS 두 파일은 "변수 → 배경/겹 → 요소 → 미디어쿼리" 순서. `galaxy.css:74` 의 구분선 하나가 전역부와 랜딩 전용부를 나눈다. 배경 두 겹은 `#starfield` z-index 그룹(`:55-61`) 뒤, 구분선 위가 규약상 자리.
- 머리 주석 규약: 근거 문서 경로 + `해소 N번` + 실측 대비비. `galaxy.css:2-3`(16:1), `:21`(15.7 / 7.8 / 7.4 / 8.2), `galaxy-reveal.css:3`(해소 14·15·20번). 실측 숫자는 다섯 개이고 `:3`·`:20` 의 "7:1" 은 기준선이지 실측이 아니다.
- `?light` 는 세 화면에 주석까지 동일한 2줄로 복제. `:root.light` 는 특정성 (0,2,0)이라 순서 무관. 깨질 지점은 순서가 아니라 짝 누락 — `--d-bg-2` 는 의도적으로 `:root` 에만 있다.
- 주석 밀도: 인라인 40%(88/222줄), `galaxy.css` 9%, `galaxy-reveal.css` 18%.
- 접두사 규약 `--g-`(공용) / `--r-`(reveal) / `--d-`(덱 전용). `.deck-` 이 `galaxy.css:98`·`:107`·`:132` 에서 이미 "랜딩 카드" 뜻으로 점유됨.
- `slides/README.md:46-51` "지켜야 할 것" 형식 = 금지형 한 줄 + 결과 한 문장. `:32-39` 자체 검사 절은 `check-render.js` 누락으로 낡음.

### similar-features

- 견본 12장 구성: hero 3, 목차(fragment 5), 수식(fragment 2), 코드(`data-line-numbers` 3단계), Mermaid, Chart, 두 칸, 표, 세로 2장.

- 개편 덱의 `.rise` 28개는 `<li>` 18, `<p>` 9, `<ul>` 1 세 유형뿐. `h1/h2/h3`, `pre`, `table`, `aside.notes`, `span.cite`, `p.muted` 에는 0건.
- 감싸는 상자는 "안쪽 낱개"(`:668-674`)와 "상자 통째"(`:947`) 두 방식 공존. `.cols` 장에는 `.rise` 0건.

- 커밋 117c55b(밝은 강의실 모드)가 이번과 1:1 대응 선례. 순서: 공용 팔레트 → 발표 도구 전용 → CSS로 안 되는 최소 조각을 각 화면에 복제 → README·안내 갱신 → favicon.
- "중복 값을 공용으로 승격한" 선례는 없음. 직전 커밋 0f4142b 는 정반대로 의도적 격리.

### integration-points

- 공용 자산 참조는 화면 3개 + CI 2줄이 전부. 퀴즈 3개와 `.claude/shared` 는 grep 0건 — 요구사항 12번의 범위 한정이 이미 성립.
- 별 색은 `starfield.js:102` 한 줄. 셀프테스트가 잠그는 것은 `starCount:200` / `maxAlpha:0.5` / `maxShift:30` 과 루프 수명. 색 단정 0건.
- `--r-*` 27개 중 12개는 공용이 안 덮음. `--r-main-font-size` 소비처는 `black.css` 의 `.reveal{font-size}` 한 줄. 48로 올리면 em 기반은 전부 따라오고, `--r-block-margin:20px`·`padding:1rem`·`.slide-number:12px` 는 안 따라옴.
- 외부 도구 초기화 순서: KaTeX(math 플러그인이 CSS를 나중에 head 에 append) → Chart(`.then()` 동기) → Mermaid(3.4MB 지연 로드 후 `Reveal.layout()`).
- 인쇄 경로 둘: `?print-pdf` 는 `reveal-print` + `print-pdf` 두 클래스, 쿼리 없는 인쇄는 `@media print` + `html:not(.print-pdf)` 로 60px 20px 강제.
- 배포: `_config.yml` 에 자산 파이프라인 없음. 캐시 무효화 쿼리 없음. `check-links.js:29` 가 `?` 앞만 보므로 버전 쿼리를 붙여도 링크 검사는 통과.
