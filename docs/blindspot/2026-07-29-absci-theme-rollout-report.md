# 1. 요구사항 구현 현황
* **개요**: 랜딩 페이지 및 발표 자료 전체에 `absci.com/technology/` 디자인 스타일(CSS 그라데이션 애니메이션 및 컬러 시스템)을 적용하였습니다.
* **배경 구현**: JS 기반의 무거운 Canvas 애니메이션 대신, 가볍고 유려한 CSS `linear-gradient` 애니메이션을 도입하여 `html` 배경에 직접 적용했습니다. 기존 `.sky-glow`, `.sky-grid` HTML 요소는 제거하였습니다.
* **스타일 일원화**: 기존의 `galaxy` 접두어를 사용하는 모든 파일(`galaxy.css`, `galaxy-reveal.css`)을 `absci` 체계로 변경하였습니다.
* **라이트 모드 지원**: `?light` 쿼리 스트링을 사용할 때 배경 애니메이션의 컬러가 밝게 변경되고, `--g-scrim`(가독성 레이어) 변수 상속을 통해 어두운 텍스트가 명확하게 보이도록 호환성을 유지했습니다.

# 2. 미해결 과제 / 부작용
* `?light` 모드 구동 시 애니메이션이 적용되도록 하였으나, 특정 환경(프린트 등)에서는 `@media print`가 동작해 애니메이션이 멈추도록 방어 코드가 적용되어 있습니다. 
* 기존 캔버스가 제거되면서 `.no-anim` 등 자바스크립트로 강제 제어하던 일부 타이밍 이슈는 브라우저의 CSS 렌더링에 완전히 위임되었습니다.

# 3. 사용자 확인 필요 (머지 전 필수 확인)
* [ ] 발표자 뷰(`?receiver`), 인쇄(`?print-pdf`) 모드에서 애니메이션 정지 기능이 CSS만으로도 원하는 대로 동작하는지 직접 확인 바랍니다.
* [ ] 모든 슬라이드의 `index.html` 내 `<div class="sky-glow">` 및 `<div class="sky-grid">`를 일괄 삭제했습니다. 직접 렌더링을 확인하세요.
