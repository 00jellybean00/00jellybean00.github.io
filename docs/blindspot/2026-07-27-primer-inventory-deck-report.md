이 프로그램은 실험실이 가진 primer 중에서 시퀀싱에 쓸 것을 골라 줍니다.
발표자료는 웹 브라우저로 넘겨 보는 형태이고 모두 28장입니다.

판정 기준의 근거와, 아직 못 미더운 점 다섯 가지도 숨기지 않고 넣었습니다.
마지막에는 매니저에게 여쭐 논의 항목 네 가지가 있습니다.

두 문제 모두 고친 뒤 28장 전부를 다시 재서 확인했습니다.

## Agent 섹션 (AI 인수인계용)

### 의도 (Intent)

외부 저장소 `primer-inventory`(커밋 `e4af260` 고정)를 실험 전문가인 매니저에게 브리핑하는 reveal.js 덱을 `slides/primer-inventory/index.html` 단일 파일로 추가한다.

목적은 두 가지다. 프로젝트 구조·방향성 설명, 그리고 논의 4개 항목(판정 기준 타당성 / 다음 우선순위 / 프로젝트 범위 / 랩 운영 연결)에 대한 피드백 수령.

덱 구성은 `2026-07-27-primer-inventory-deck-explainer.md`가 장 단위로 확정했다. 본론 24장(1부 3 / 2부 3 / 3부 5 / 4부 4 / 5부 2 / 6부 1 / 7부 6) + 부록 4장 = 리프 섹션 28.

핵심 설계 원칙: **약점 선제 공개**. 매니저가 실험 전문가라 어차피 찾아내므로, Tm 40도 대 반응온도 50도 / 경계 40.5도 / `optimistic` 프리셋 비단조성 / SnapGene 미검증 / 열역학 검증 0건을 전용 슬라이드 2장으로 먼저 밝힌다.

### 제약 (Constraints)

- **원문 무결성.** 실행 출력 3블록과 파이썬 코드 3블록은 원본 파일에서 복사한 그대로여야 한다. 스크립트로 바이트 단위 대조를 통과했다. 유일한 예외 두 곳은 화면에 명시했다 — 127칸 줄 접기(`:226`), `find_bindings`의 영어 docstring 7줄 생략(`:249`).
- **레이아웃 상한.** 슬라이드 논리 크기 960×700px. `pre code`의 가용 폭 921.6px, 가용 높이 448px(`galaxy-reveal.css:102` `max-height:480px` − padding 32px). 인라인 `font-size`는 전부 이 상한에서 역산했고 5% 여유를 뒀다.
- **견본 덱 불가침.** `slides/demo/index.html`은 수정하지 않는다. 복사할 때 빼는 방식만 쓴다.
