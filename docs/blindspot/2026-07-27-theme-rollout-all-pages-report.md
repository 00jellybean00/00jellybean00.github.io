### 리뷰 포인트 (개발자용)

- `assets/galaxy.css:1-53` — 팔레트 전면 교체. `--g-accent` 는 참고 덱 원본 `#9B82FF`(6.70:1)가 아니라 `#A088FF`(7.11:1). 이 파일 머리 주석이 스스로 AAA 7:1 을 약속하므로 원본으로 되돌리면 그 약속이 깨진다.
- `assets/galaxy.css:19-21` — `--g-bg-2` 는 `:root` 에만 있고 `:root.light` 에는 **의도적으로 없다**. 짝을 만들면 밝은 모드에서 코드 상자가 밝아져 `galaxy-reveal.css:93-97` 의 의도가 조용히 깨진다.
- `assets/galaxy.css:117-134` — 등장 움직임. 초기 상태를 `@keyframes from` 에만 두고 `fill-mode: backwards`. 기본 규칙에 `opacity:0` 을 두면 전체 보기·인쇄·움직임 줄이기·발표자 화면 넷에서 내용이 영구히 사라진다.
- `assets/galaxy-reveal.css:194-197` — 발표 화면용 등장 조건. `animation` 단축이 `animation-delay` 를 초기화하고 선택자 특정성이 (0,6,2)라 하위 규칙이 못 이긴다. **이 규칙에 `animation-delay` 를 직접 적는 수정은 시차 등장을 통째로 죽인다.** 지연은 `--step`/`--lead` 로만 전달할 것.
- `assets/galaxy-reveal.css:5-12` — `--r-main-font-size: 48px` 이 `:root` 에 있다. 각 덱의 `Reveal.initialize` 의 `height: 800` 과 짝이다. 새 덱이 `height` 를 빠뜨리면 기본값 700 에 48 이 얹혀 글자가 14% 커진다.
- `assets/galaxy-reveal.css:57-62` — 강조 세 자리가 서로 다른 색을 쓴다(소제목 민트 / 표 머리 보라 / 굵은 글자 호박). 이 둘은 옮기는 과정에서 한 번 유실됐다가 복구한 규칙이다.
- `.github/check-render.js:114-139` — 검사 2. 결과 필드 이름과 가드 조건이 어긋나면 블록 전체가 조용히 건너뛰어진다. 실제로 한 번 그렇게 죽었다.
- `.github/check-render.js:229-266` — 첫 화면 전용 검사. 발표 도구 대기와 장 순회를 걷어낸 판본이다. 검사 5·7 만 여기 해당한다.
- `.github/check-render.js:270-290` — 공용 CSS 규칙 세기. 색이 공용으로 옮겨 간 뒤 화면 파일만 세면 놓치므로 추가했다.

### 의도적 범위 제외

- **`assets/starfield.js` 미수정.** 별 색이 새 바탕 위에서 4.62 → 4.60 으로 사실상 불변. 보라로 물들이면 2.43 으로 떨어져 별이 사라진다.

- **코드 상자 위 대비 7:1 미적용.** 지키려면 보라·분홍·민트의 코드 상자 전용 변종을 따로 만들어야 한다. 자동 검사 기준 4.5 는 넘는다.

- **demo 5·6·7·8·9번 장 등장 미적용.** 5번은 후보가 보조 글뿐, 6·7·9번은 대상 요소 0개, 8번은 두 칸 배치(primer 선례).

### 구현 노트 요약

계획 이탈:

1. 고칠 공용 스타일 파일이 셋에서 **둘**로 줄었다. 별 색을 안 바꾸기로 해서 `starfield.js` 를 고칠 일이 없어졌다.
2. demo 등장 대상 장이 여섯에서 **다섯**으로 줄었다. 5번 장의 유일한 후보가 보조 글이라 대상 기준에 걸렸다.
3. 등장 대상 요소가 셋에서 **넷**으로 늘었다. 소개 문구를 더했다. 첫 화면은 붙이는데 demo 만 빼면 어긋난다.
4. 설계 문서에 없던 판단 셋이 추가됐다. 밝은 모드 상자 배경의 기본값 지정, hero 그러데이션 3색 교체, 구문 색을 고정값으로 유지.

보수적 선택:

- 별 색을 설정값으로 빼지 않고 값에 그대로 뒀다. 쓰는 곳이 한 줄뿐이라 얻는 것이 없다.
- demo 4번 장은 내용을 지우지 않고 말만 줄였다.
- 작업을 `theme-rollout` 브랜치에서 했다. 공용 파일을 건드려 세 화면이 동시에 바뀌므로 확인 전 배포를 막았다.

**사고 셋 — 전부 "통과했는데 틀린" 유형:**

1. **`git checkout` 으로 미커밋 변경 유실.** 회귀 시험 후 되돌릴 때 사용. 그 파일은 커밋 이력이 없어 이번 작업분 열 곳 이상이 한 번에 사라졌다. 검사를 다시 돌려 고쳤던 값이 되살아난 것으로 발견, 전부 복구. 이후 복사본 방식으로 전환.
2. **검사 2가 조용히 죽음.** 결과 필드 이름을 바꾸며 가드 조건을 안 고쳐 블록 전체가 건너뛰어졌다. 결함을 다시 심어 보고 나서야 발견. "통과"는 검사가 도는지에 대해 아무것도 알려 주지 않는다.
3. **색 규칙 둘 유실.** 굵은 글자의 호박색과 소제목의 민트색이 옮기는 과정에서 사라졌다. 새 색 이름의 사용처가 0인 것이 단서였다. 대비비는 둘 다 기준을 넘어 검사가 원리적으로 못 잡는다.
